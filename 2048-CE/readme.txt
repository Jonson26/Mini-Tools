2048 CE
=======

©2026 Filip Jamroga

The classic game about merging tiles, now on Windows CE!

Requires PocketC runtime.

Features:
 * Full 2048 implementation
 * Saves your high score
 * Supports both touch and arrow key controls

This game is Freeware, but if you enjoy the game feel free to donate to my Ko-fi: ko-fi.com/jonson26
